# ASCII Art Generator

Генератор ASCII-арта из изображений. Загрузите картинку, настройте параметры и получите текстовый арт прямо в браузере.

## 🔗 Живая версия

https://asciiargenerator.netlify.app

## Возможности (MVP)

- **Загрузка изображения**: drag & drop в зону загрузки или кнопка выбора файла
- **Поддерживаемые форматы**: PNG, JPG, JPEG, GIF, WEBP
- **Настройки генерации**:
  - Ширина ASCII-арта (в символах, 20–300)
  - Наборы символов: *Standard*, *Detailed*, *Blocks*, *Minimal*
  - Инверсия яркости (тёмный/светлый фон)
  - Цветной ASCII (сохранение цветов пикселей)
- **Живой предпросмотр**: арт пересчитывается при изменении настроек без повторной загрузки файла
- **Экспорт результата**:
  - Скачать `.txt`
  - Скопировать в буфер обмена
  - Скачать как PNG (рендер на canvas)
- **Корректные пропорции**: учёт соотношения сторон символа ~0.5
- **Обработка ошибок**: неверный формат файла, слишком большое изображение (лимит 10 МБ)
- **Офлайн-работа**: нет внешних зависимостей и CDN, открывается по двойному клику на `index.html`

## Технологический стек

- Чистый HTML / CSS / JavaScript (без фреймворков)
- Canvas API для анализа пикселей и рендера PNG
- Никакого бэкенда — вся обработка на клиенте
- Адаптивная вёрстка, тёмная тема по умолчанию

## Структура проекта

```
ASCII-Art-Generator/
├── index.html          # Разметка: загрузка, настройки, предпросмотр, экспорт
├── css/
│   └── style.css       # Тёмная минималистичная адаптивная вёрстка
├── js/
│   ├── app.js          # Точка входа, состояние приложения, живой предпросмотр
│   ├── config.js       # Конфиг: пресеты символов, дефолтные настройки, лимиты
│   ├── converter.js    # Пиксели → яркость → символ, поправка пропорций
│   ├── exporter.js     # Экспорт .txt, копирование в буфер, PNG
│   ├── loader.js       # Загрузка файла: drag & drop, валидация
│   ├── renderer.js     # Рендер ASCII в <pre> и на canvas
│   └── ui.js           # Интерфейс: ошибки, уведомления, инфо о файле
└── README.md
```

## Как запустить локально

**Способ 1 (без сервера):**
Откройте файл `index.html` двойным кликом в любом браузере. Всё работает офлайн.

**Способ 2 (локальный сервер):**
```bash
# Python
python -m http.server 8000
# http://localhost:8000

# или Node (npx serve / npx http-server)
npx serve .
```

## Как задеплоить на статический хостинг

Проект полностью статический — просто загрузите все файлы в репозиторий или папку хостинга. Никаких изменений в коде не требуется.

- **Netlify**: подключите GitHub-репозиторий или перетащите папку проекта в панель управления. Сайт доступен по ссылке: https://asciiargenerator.netlify.app
- **GitHub Pages**: Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/(root)`
- **Vercel**: импортируйте репозиторий, фреймворк не выбирайте (Static)
